# 旧工程归档

`v1.4.0/` 保存重构前的 PowerShell / VBScript 工程、启动入口、测试、安装打包脚本与当时的文档。它是维护参考，不是当前开发入口；当前应用位于仓库根目录的 `src/`。

旧脚本以自身目录为工作目录。需要维护时，请在隔离环境中运行；不要让旧版和新版同时接管轮播任务。打包文件清单完整保留。Inno 编译器不随归档复制，可通过旧版 `Build-Installer.ps1 -CompilerPath` 指定。

个人配置、图片缓存、测试结果、构建工具和历史安装包不属于旧源代码，本次没有移动它们。归档内生成的 `config.json`、`data/`、`dist/` 同样由 Git 忽略。
